# What is eRPN?
eRPN is an app for the TI-Nspire calculator chain that acts as a revamped version of HP's Reverse Polish Notation notation format. Unlike HP, eRPN also adds CAS support with Giac, and many other features that vanilla HP calculators do not have:



# Installation

Upload "erpn.tns" to your calculator, then "erpn_launcher.tns". Ndless is required for this to function.
Open the launcher, then close it. Then, after clicking the keys "RPN" on the keypad anywhere, eRPN will open. Opening it manually also works, so the launcher is not necessary.
